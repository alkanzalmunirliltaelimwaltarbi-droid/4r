# حاسبة الرخام والغرانيت — الإصدار النهائي 2.3

نسخة PWA عربية RTL، Mobile-First، تعمل دون إنترنت بعد التثبيت، مع حفظ محلي للبيانات.

## أهم الإصلاحات
- إصلاح خطأ حفظ الطلب الناتج عن عدم وجود دالة حساب إجمالي الدفعات `paymentTotalUSD`.
- تحسين التحقق من القياسات ومنع حفظ طلب بلا قياس صالح.
- دعم الأرقام العربية والفواصل العربية/الإنجليزية في الإدخال.
- تحسين الحفظ المحلي عبر LocalStorage مع IndexedDB كنسخة تخزين مساندة.
- معالجة البيانات القديمة وترحيلها من الإصدار السابق عند فتح البرنامج.
- الحفاظ على رقم الطلب وتاريخ الإنشاء عند تعديل الطلب.
- تحسين سجل الدفعات وحساب الدفعات بالدولار والليرة السورية حسب سعر الصرف المسجل للدفعة.
- تحسين الطباعة A4 أفقي، RTL، نسختين متطابقتين، وإزالة سطر تعريف المصمم من التقارير المطبوعة.
- تحسين تصدير Excel بصيغة XLSX حقيقية مع ثلاث أوراق: الطلبات، الدفعات، الملخص، واتجاه RTL.
- تحديث Service Worker إلى الإصدار 2.3 لإجبار الأجهزة على استلام الملفات الجديدة.
- تحديث Manifest إلى الإصدار 2.3.

## الاختبارات المنفذة
- فحص صياغة JavaScript بالكامل.
- فحص صياغة Service Worker.
- فحص JSON الخاص بـ Manifest.
- اختبار إنشاء طلب وحساب المساحة والمتر الجاري والإجمالي.
- اختبار تحويل الدفعات بين الدولار والليرة.
- اختبار حفظ الطلب وتعديله دون إنشاء سجل مكرر.
- اختبار حفظ تاريخ إنشاء الطلب عند التعديل.
- اختبار منع حفظ القياسات غير الصالحة.
- اختبار إنشاء تقارير القياسات والحسابات.
- اختبار ملف XLSX فعلي والتحقق من سلامة جميع أجزائه كملف ZIP.
- فحص عدم وجود مراجع حرفية إلى عناصر HTML غير موجودة.

## التثبيت
ارفع الملفات كما هي إلى مجلد الموقع، ثم افتح الموقع من HTTPS وأضفه إلى الشاشة الرئيسية/ثبّته كتطبيق.
